# MandatePay Web App (`apps/web`)

Next.js App Router web application housing:
- MandatePay Owner Console (in-browser Ed25519 signing, mandate builder, approval inbox, live audit feed)
- Retailer Inventory & Pooling App (stock cover, agent trace, pool commitments)

- **Port**: 3000
- **Base URL**: `http://localhost:3000`
- **Owner**: Frontend Engineer / Software Developer
